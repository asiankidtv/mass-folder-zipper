# mass-folder-zipper
A utility tool used to zip large number of folders. Will zip all files inside a folder into a zip file of the same name as the parent folder. I originally created this to help zip large amounts of folders for a game, but I realized this could also be used as a general purpose tool.

## Tutorial:
Set the CURRENT_DIRECTORY variable in main.py to the folder containing all the folders you'd like to zip. Set the RESULT_DIRECTORY variable to the folder where the resulting zip files will end up.
